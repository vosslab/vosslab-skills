# Select the design problem

Start with the user's intended outcome and the current game. Resolve missing
preferences from explicit direction, established project evidence, then a
documented sensible choice. Continue authorized work without waiting for taste
decisions. Match the scale of the intervention to the request.

| Request or symptom | First action | Read next |
| --- | --- | --- |
| New game or major expansion | State the promise and prototype its uncertain interaction | [project_workflow.md](project_workflow.md) |
| Working but boring or repetitive | Inspect a play sequence and identify already-solved repetition | [design_principles.md](design_principles.md) |
| Sluggish, slippery, or unfair controls | Reproduce movement in the actual encounter and inspect input, response, space | [testing_and_oracles.md](testing_and_oracles.md) |
| Generic characters or scenery | Inspect silhouettes, material behavior, personality, and the established art | [art_direction.md](art_direction.md) |
| Progress feels empty | Compare the world before, during, and after accomplishment | [art_direction.md](art_direction.md) |
| Biology feels like a quiz overlay | Identify the subject relationship a player action can express | [design_principles.md](design_principles.md) |
| Individually good modules feel disconnected | Compare their behavior with the shared experience brief | [project_workflow.md](project_workflow.md) |

For an underspecified improvement request, inspect the opening, representative
later encounters, a failure/retry, and a payoff. Choose connected changes with
the strongest evidence of benefit. Preserve successful encounters and identity.

Use [case_studies.md](case_studies.md) for concrete decision examples. A source
game's palette, control scheme, level count, audio default, or model choice is
project context, not an automatic requirement for another game.

Routine dependency updates, mechanical renames, and typo fixes normally need
the target's existing engineering checks rather than a game-design intervention.
