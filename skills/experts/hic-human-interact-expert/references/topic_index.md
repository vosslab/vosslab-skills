# Topic index

Start here. Match the request to a row, open the named guide, and produce the
listed evidence artifact before advising implementation.

## Problem routing table

| User question | HCI route | Primary evidence | Runnable oracle |
| --- | --- | --- | --- |
| Discover novice expectations | Interviews and mental-model research | Vocabulary and expectation map | Scenario walkthrough |
| Understand a laboratory or kiosk workflow | Task analysis | Goal-action model and error paths | Complete modeled tasks |
| Check whether a first-time flow is learnable | Cognitive walkthrough | Action-question ledger | Expert walkthrough |
| Find general usability issues | Heuristic evaluation | Severity-ranked findings | Guideline trace check |
| Learn whether people complete a goal | Usability evaluation | Script, task measures, findings | Timed completion run |
| Choose between designs or settings | Evaluation study | Hypothesis and measure plan | Compare measured outcomes |
| Explain perception, memory, or recognition guidance | Cognitive design rationale | Guideline ledger | Interaction inspection |
| Choose voice, gesture, haptic, or XR interaction | Interaction-technique comparison | Context and trade-off matrix | Representative task run |
| Define inclusive interaction behavior | Accessibility and platform guidance | WCAG and platform trace | Automated and manual checks |
| Build a component or responsive layout | UI implementation handoff | Task brief and acceptance criteria | UI workflow test |

## Corpus-absent route

Use this index without the local corpus: select the HCI route, consult current
W3C WCAG and the target platform's human-interface guidelines, and run the
runnable oracle named in [testing_and_oracles.md](testing_and_oracles.md).
Carry the resulting task model, guideline ledger, or study plan into the
project workflow.
