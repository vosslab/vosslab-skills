# Local books

Use this source map to select a local book conversion for an HCI method task.
The six books live in `references/local-only/` and remain local. Open a bare
path and grep the listed terms; use [reference_survey.md](reference_survey.md)
for evidence-backed topic coverage.

## Reading order

1. `references/local-only/User_Experience_Methods_and_Tools_in_Human-Computer_Interaction-2025.md`
   Start here for requirements, ethnography, interviews, task modeling,
   questionnaires, inspections, usability tests, and participatory design.
   grep `requirements engineering`, `task analysis`, `usability testing`.
2. `references/local-only/Interaction_Design_Beyond_Human-Computer_Interaction-2023.md`
   Use for the interaction-design lifecycle, requirements discovery, cognitive
   aspects, evaluation studies, inspections, and analytics. grep
   `interaction design process`, `evaluation studies`, `heuristic evaluation`.
3. `references/local-only/Designing_with_the_Mind_in_Mind_User_Interface_Design_Guidelines-2021.md`
   Use for perception, visual structure, attention, memory, recognition,
   learning, decisions, timing, and error-prevention guidance. grep
   `perception`, `memory`, `recognition`.
4. `references/local-only/Interaction_Techniques_and_Technologies_in_Human-Computer_Interaction-2025.md`
   Use for interaction styles, multimodal systems, devices, haptics, gestures,
   voice, sound, wearables, tangible interaction, and XR. grep
   `interaction styles`, `multimodal interaction`, `gesture-based interaction`.
5. `references/local-only/Designing_the_User_Interface_Strategies_for_Effective_Human-Computer_Interaction-2018.md`
   Use for an established interface-design process, universal usability,
   guidelines, interaction styles, prototypes, and usability evaluation. grep
   `requirements analysis`, `usability testing`, `accessibility`.
6. `references/local-only/Architecture_in_the_Age_of_Human-Computer_Interaction-2025.md`
   Use for ethnographic meaning, ecological and social affordances, movement,
   embodied interaction, and interfaces situated in physical places. grep
   `ethnography`, `affordance`, `embodied interaction`.

## Practical routing

- Use the first two books to choose and conduct research, requirements, task,
  and evaluation methods.
- Use the third book to turn cognitive evidence into concrete interaction
  guidance.
- Use the fourth book to compare modalities and interaction techniques.
- Use the fifth book for broad interface-design principles and universal
  usability context.
- Use the sixth book when physical place, movement, cultural meaning, or
  embodied interaction shapes the design problem.
- Use W3C WCAG and the target platform's human-interface guidelines for current
  accessibility conformance and platform-specific implementation detail.
