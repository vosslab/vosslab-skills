# SVG reference survey

This survey records verified search routes in the local corpus. Ratings mean
**strong** for dedicated actionable treatment, **partial** for a useful section
in a broader source, and **context** for historical or inspirational material.

## How to use the survey

- Search the exact term in the named bare path and read the surrounding passage.
- Prefer a strong source, then corroborate damaged OCR or cross-disciplinary
  questions with a second source.
- Use current SVG specifications, browser documentation, software manuals,
  publication requirements, and technical standards for version-sensitive facts.
- Use the committed workflow and testing guides on installations containing the
  portable skill alone.

## Object illustration working stack

ordinary manufactured objects. Its verified sections progress from coordinate frames
and ellipses through planned orthographic masses, perspective volumes, moving parts,
surface cuts, radii, and fillets.

## Coverage gaps

- Mastering SVG and Generative Art with JavaScript and SVG are the current local
  implementation routes for canvas, paths, transforms, gradients, masks, groups,
  symbols, and reuse.
- Use current SVG 2, SVG Accessibility API Mappings, WAI guidance, and target
  browser evidence for semantic and accessibility behavior.
- Use current software documentation for Illustrator, Inkscape, optimization,
  and export interfaces.
- Use the actual publisher specification, target ISO/ASME edition, or fabrication
  contract for compliance decisions.
- Use subject-matter sources and expert review to establish scientific claims beyond
  the supplied evidence.

## Current primary routes

- [SVG 2 document structure](https://www.w3.org/TR/SVG2/struct.html) for structural,
  descriptive, reuse, and ARIA semantics.
- [SVG 2 coordinate systems](https://www.w3.org/TR/SVG2/coords.html) for viewport,
  `viewBox`, units, and transforms.
- [SVG 2 paths](https://www.w3.org/TR/SVG2/paths.html) for path-data syntax and
  geometry behavior.
- [SVG 2 accessibility support](https://www.w3.org/TR/SVG2/access.html) and the
  specifications it links for current accessibility requirements and mappings.
