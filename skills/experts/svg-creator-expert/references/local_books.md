# Local SVG and illustration books

Use this map with [reference_survey.md](reference_survey.md). The 16 book
conversions stay machine-local. Search a named term in the bare path and read the
surrounding passage. On installations containing the committed guides alone, use
current primary SVG documentation, target evidence, and subject-matter sources.

## Default object-illustration stack

For a request such as "make an SVG of a garbage dumpster," select one focused
passage from each layer that changes the drawing:

1. Use Robertson's *How to Draw* for manufactured-object construction,
   three-quarter perspective, volumes, ellipses, rotations, cuts, and surface
   detail. The repaired and audited conversion is the key construction reference for
   ordinary object illustration.
2. Establish the SVG coordinate system and structured reuse with Mastering SVG,
   searching `viewBox and viewport in SVG`, or the generative SVG source,
   searching `Grouping and Reusing Elements`.
3. Add line/depth hierarchy from the biological illustration handbook, searching
   `heaviest lines are used to draw the closest parts`, or from Engineering
   Graphics, searching `Alphabet of Lines`.
4. Add vector layers, Boolean construction, and restrained shading when they improve
   form communication, using Quick and Easy Vector Graphics or Adobe Illustrator
   Classroom.
5. Control composition and detail with The Everything Drawing Book, searching
   `Thumbnail Sketches and Working Drawings`, and the handbook's `CLARITY` section.

Use [object_illustration.md](object_illustration.md) for the complete creation
loop. Subject references establish the object's actual features; these books
guide how to construct and communicate those features in SVG.

## Object construction

1. `local-only/object_construction/How_to_Draw_Drawing_and_Sketching_Objects_and_Environments_from_Your_Imagination-2013.md`
   is the primary drawing source for perspective grids, the X-Y-Z
   coordinate system, boxes, manufactured objects, ellipses, rotations, volumes,
   cuts, surface construction, and presentation overlays. Its repaired and audited
   Markdown provides verified section routes in
   [reference_survey.md](reference_survey.md).

## SVG authoring

2. `local-only/svg_authoring/Mastering_SVG-2018.md` covers SVG structure,
   coordinate systems, shapes, paths, transforms, clipping, masks, filters,
   HTML/CSS/JavaScript integration, accessibility, animation, and optimization.
   Treat library and browser-support details as dated.
3. `local-only/svg_authoring/Generative_Art_with_JavaScript_and_SVG-2024.md`
   covers programmatic construction, shapes, definitions, reuse, grids,
   randomness, noise, paths, animation, interaction, and filters.

## Vector tools

4. `local-only/vector_tools/Quick_and_Easy_Vector_Graphics-2020.md` is the
   concise conceptual route for primitives, drawing order, Boolean operations,
   transforms, text, masks, anchor points, and Bezier curves.
5. `local-only/vector_tools/Adobe_Illustrator_Classroom_in_a_Book_2022_Release-2022.md`
   is the editor-workflow route for selection, shape/path construction, pen and
   curvature tools, layers, type, color, masks, symbols, and asset export.
   Verify current UI instructions in current Adobe documentation.

## Scientific illustration

6. `local-only/scientific_illustration/A_Handbook_of_Biological_Illustration-1988.md`
   covers observation, clarity, measurement, scale, publication reduction,
   preliminary drawings, biological rendering, graphs, maps, and lettering.
7. `local-only/scientific_illustration/Preparing_Scientific_Illustrations_a_Guide_to_Better_Posters_Presentations-1996.md`
   covers audience, purpose, simplification, diagrams, figures, graphs, labels,
   reduction, slides, posters, and publication planning.
8. `local-only/scientific_illustration/Botanical_Art_with_Scientific_Illustration-2018.md`
   covers scientific background research, specimen selection, observation,
   anatomy, perspective, tone, color, composition, and botanical technique.
9. `local-only/scientific_illustration/Medical_Illustration_in_the_Courtroom_Proving_Injury_Causation_and_Damages-2024.md`
   covers visual explanation of medical information, imaging sources,
   case-specific anatomy, presentation formats, expert review, and accuracy.
10. `local-only/scientific_illustration/Images_of_Science_a_History_of_Scientific_Illustration-1992.md`
    provides historical context for how anatomy, zoology, botany, geology,
    geography, and astronomy have been represented. Use it for precedent and use
    current subject-matter sources as scientific authority.
11. `local-only/scientific_illustration/The_Beauty_of_the_Flower-2023.md`
    provides botanical-illustration history, science/illustration context,
    specimen habit and habitat, and observation themes.

## Technical drawing

    line roles, venue drawings, lettering, scenic elements, and build handoff.

## Local SVG asset inventory

`local-only/LOCAL_SERVIER_SVG_FILE_PATHS.txt` is a machine-local inventory of
existing Servier-derived SVG paths. Use it as a search index when a biological or
medical component may already exist. Search `/Lab_apparatus/` for equipment such as
centrifuges, cuvettes, microscopes, and spectrophotometers. Inspect the selected SVG
itself and verify its license, attribution, visual fit, and owning source before reuse.
The absolute paths are machine-specific. This inventory provides subject references;
the drawing books provide construction guidance.

## Source boundary

- Start with one relevant source family and one focused passage. Add another
  source when corroboration or a second discipline changes the decision.
- Treat converted prose as conceptual evidence. Verify current syntax, browser
  support, accessibility behavior, software UI, publisher requirements, and
  technical standards in current primary sources.
- Keep the corpus optional. The committed guides and current primary sources provide
  a complete route on a clean installation.
