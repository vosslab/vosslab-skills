# Dimension prompt: decomposability

Can this idea be broken into independent parts, or is it irreducibly whole?

Possible values: **fully decomposable / mostly decomposable / partially / mostly atomic / fully atomic.**

Substitution test: take an atomic idea and try to decompose it (sometimes the decomposition reveals that what looked atomic was hiding seams). Take a decomposable idea and ask what would happen if you fused its components into a single unit.
