# Dimension prompt: purpose

What's the purpose of this idea? Does it have one purpose, multiple, or none?

Possible values: **single-purpose / multi-purpose / re-purposable / purposeless / anti-purposed.**

Substitution test: a version of this idea with the *opposite* purpose. A version with *no* purpose. A multi-purpose version of a single-purpose tool. Purpose-substitution is especially generative for tools, institutions, and rituals — most have inherited a purpose that's no longer load-bearing.
