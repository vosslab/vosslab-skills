# Dimension prompt: age

How old is this idea? Is it ancient, modern, or recent?

Possible values: **prehistoric / ancient / pre-industrial / industrial / modern / postmodern / emerging.**

Substitution test: re-instantiate the idea in another era. What's the bronze-age version of this? The 22nd-century version? Era-substitution often reveals which features of the idea are genuinely about the idea and which are about its current technological substrate.
