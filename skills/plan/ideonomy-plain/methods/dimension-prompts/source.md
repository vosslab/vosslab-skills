# Dimension prompt: source

Where did this idea come from?

Possible values (this dimension is open-ended, but candidate categories): **biological-evolution / cultural-evolution / individual-invention / institutional-design / accident / convergent-emergence.**

Substitution test: this idea exists; imagine it had arrived via a different source. Same idea? A modular smartphone designed by an institution vs one that emerged from a thousand small inventions vs one that fell from a comet — each is a different ideational variant.
