# Dimension prompt: size

How big is this idea, or its typical instances?

Possible values: **microscopic / human-scale / building-scale / city-scale / planetary / cosmic.**

Substitution test: scale up by 1000×. Scale down by 1000×. The miniature and gigantic versions are often each their own discipline (e.g., miniaturization in electronics, megastructure architecture). Each scale-substitution exposes a different population of related ideas.
