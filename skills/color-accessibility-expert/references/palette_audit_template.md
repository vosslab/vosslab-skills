# Palette audit template

Skeleton for a target repo's `docs/PALETTE_CONTRAST_AUDIT.md`. This is the one
documentation artifact the `color-accessibility-expert` skill generates:
`generate_palette_audit.py` builds it from evidence gathered in the target repo
during the current run.

The generic WCAG contrast method (target ratio, luminance math, calculators)
lives in `docs/COLOR_CONTRAST_ACCESSIBILITY.md`, which is propagated read-only
from `starter-repo-template` and assumed present. The audit file never restates
that method; it cites it and lists this repo's actual palette evidence.

Carry a zero-contamination bar: the audit table contains only file paths and hex
values actually observed in the target repo this run, never a value or path
copied from another repo's audit.

## Evidence-only checklist

Pass every item before writing the audit file:

- Every file path listed in the audit table was Read in the target repo during
  this run.
- Every hex value listed in the audit table appears in this run's
  `extract_colors.py` output.
- Zero content in the audit table was copied from another repo's
  `docs/PALETTE_CONTRAST_AUDIT.md`.

## Audit file shape

`generate_palette_audit.py` renders three parts: the title, a one-line
provenance note (generating skill, target ratio, and background), and the audit
table. One row per distinct hex/source-file pair:

```markdown
# Palette contrast audit

Generated by the color-accessibility-expert skill from this run's evidence,
measured against background `#ffffff` at a target of 5.5:1. For the WCAG
contrast method, see the propagated `docs/COLOR_CONTRAST_ACCESSIBILITY.md`.

## Palette audit

| Source file | Hex | Ratio vs background | Status |
| --- | --- | --- | --- |
| src/style.css | #4477aa | 4.90:1 | FAIL -- suggested replacement #2c527a (6.02:1) |
| src/style.css | #1a1a1a | 15.34:1 | PASS |
```

- **Source file**: the file path only, deduplicated per file. Line numbers stay
  in terminal tooling output (`extract_colors.py`, `audit_palette.py`), not in
  the committed audit file, so the file stays stable as sources grow.
- **Hex**: the color exactly as found in the source file.
- **Ratio vs background**: the measured contrast ratio against the background
  used for this audit run.
- **Status**: `PASS`, or `FAIL` plus the suggested replacement hex and its
  ratio from `adjust_color.py`.

When the target repo has no color literals to report,
`generate_palette_audit.py` writes no audit file and says so on stdout: a
colorless repo carries no `docs/PALETTE_CONTRAST_AUDIT.md`.
