# Manager contract

The manager coordinates the approved plan and assigns implementation to subagents.

## Manager owns

- Task and dependency tracking.
- Dispatch decisions.
- Read-only report and diff review.
- Follow-up assignments.
- User-facing status and completion summaries.

## Subagents own

- File changes.
- Plan-defined verification.
- Fixes from review findings.
- Evidence-rich handoffs.

## Completion handoff

The manager reports completed plan tasks, verification results, review status, concerns, and
residual risks.
