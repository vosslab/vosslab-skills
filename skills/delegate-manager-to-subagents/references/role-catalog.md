# Role guidance

Use the roles and ownership defined by the approved plan. When the plan leaves a role open, choose
the smallest role that completes the task.

## Common roles

| Role | Responsibility |
| --- | --- |
| implementer | Make the assigned file or behavior changes. |
| reviewer | Independently compare the change with the plan and evidence. |
| tester | Run or maintain plan-defined verification. |
| documentation | Update plan-required documentation and changelog entries. |

Assign implementation and review to separate subagents. Use specialized agents when the task needs
their expertise.

## Role handoff

Each role reports:

- Plan task completed.
- Files changed or reviewed.
- Commands and results.
- Findings or concerns.
- Residual risks and follow-up work.
