# Brief examples

Use the approved plan's structure and wording. Keep the brief proportional to the task.

## Implementation brief

```text
Plan task: [path and task text]
Context: [dependencies and relevant background]
Ownership: [files or behavior]
Verification: [commands from the plan]
Handoff: [files, results, concerns, residual risks]
```

## Review brief

```text
Plan task: [path and task text]
Change: [diff or changed files]
Evidence: [commands and results]
Review: compare the change with the plan and report concrete findings with file and line references
```
