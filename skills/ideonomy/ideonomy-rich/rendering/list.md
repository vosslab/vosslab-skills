# Rendering: list

Lists are the simplest organon — but a flat bullet list squanders the medium. In ideonomy-mono, lists carry rank, group, and emphasis through markers.

## Form

Group with rounded panels `╭─╮ ╰─╯`. Within each group, mark items with role-symbols.

## Worked example — *opposites of meditation*

```
╭─────────────────────────────────────────────────────────────────────────────╮
│                            ◆  OPPOSITES  ◆                                  │
│                negate one definitional property at a time                   │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   ★  accidental attention                                                   │
│      ─ negates: intentional                                                 │
│      ─ practices that cultivate noticing without trying to                  │
│      ─ peripheral-vision walks · random alarms · spontaneous-noticing       │
│                                                                             │
│   ●  outward-directed attention                                             │
│      ─ negates: inward-directed                                             │
│      ─ noticing the world rather than the self                              │
│      ─ citizen science · naturalist journaling · slow cinema                │
│                                                                             │
│   ●  inattention practice                                                   │
│      ─ negates: aimed at attention                                          │
│      ─ deliberately cultivating not-noticing                                │
│      ─ spam-blindness training · equanimity drills                          │
│                                                                             │
│   ▒  interrupted attention practice                                         │
│      ─ negates: continuous over a session                                   │
│      ─ defined by the interruption pattern itself                           │
│                                                                             │
│   ▒  instrumented attention                                                 │
│      ─ negates: no instrumental goal                                        │
│      ─ explicit output as the practice                                      │
│                                                                             │
╰─────────────────────────────────────────────────────────────────────────────╯
```

## Conventions

- `★` = the most surprising / generative entry, only ever ONE per list
- `●` = canonical, well-formed entry
- `▒` = partial / less-developed / weakly-attested
- Sub-bullets use `─` (en-dash) with deeper indent
- Group framed in rounded `╭─╮`; the group title centered in the top bar with `◆ ◆` flanking
- Width: outer frame ≤ 80 chars

## Drama

If the list has a clear winner — the negation that produced something genuinely new — flag it `★` and lead with it. The reader's eye lands on `★` first; let that placement do work.

## Anti-patterns

- Every item flat-bulleted with `-` → wasted opportunity, no hierarchy
- Multiple `★` → the symbol means *one*; redefine to `▲`/`◆` if you need more roles
- Long prose under each entry → break into ` ─ ` sub-bullets, each ≤ 80 chars
